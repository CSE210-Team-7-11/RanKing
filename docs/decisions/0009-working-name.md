# ADR-0009 | Use RanKing as the working name

## Context and Problem Statement

The project needed a shared name for the app and its repository.

## Considered Options

- LevelUp.
- RankUp.
- RanKing, a play on "ranking" with emphasis on "King."

## Decision Outcome

Use RanKing as the working name.
